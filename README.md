#M365

##Om prosjektet

###Dette prosjektet er ei enkel nettside som presenterer tre applikasjonar frå Microsoft 365: Word, Excel og PowerPoint.

###Målet med nettsida er å gi brukarane ei kort innføring i kva dei ulike applikasjonane blir brukte til.

##Applikasjonar

##Microsoft Word

###Word er eit tekstbehandlingsprogram som blir brukt til å skrive, redigere og formatere dokument.

##Microsoft Excel

###Excel er eit reknearkprogram som blir brukt til å organisere informasjon, utføre utrekningar og lage diagram.

##Microsoft PowerPoint

###PowerPoint er eit presentasjonsprogram som blir brukt til å lage lysbilete med tekst, bilete og andre visuelle element.

##Korleis nettsida fungerer

###På framsida finn du tre klikkbare kort, eitt for kvar applikasjon.

###Når du klikkar på eit kort, kjem du til ei eiga underside med meir informasjon om applikasjonen.

##Teknologi

#Nettsida er laga med:

###HTML – for å strukturere innhaldet på nettsida.

###CSS – for å bestemme utsjånaden og utforminga av nettsida.

###WebStorm – som utviklingsverktøy.

##Formål

#Prosjektet er laga som ei øving i webutvikling, med fokus på HTML, CSS, bilete, lenkjer og navigasjon mellom nettsider.
